🌐 Local Server Synchronization Guide

The Background Sync feature allows this POS terminal to automatically send completed and refunded orders to a central local server (e.g., a main computer in the restaurant manager's office) every 30 seconds. This is useful for multi-branch or multi-register setups.

Step 1: Locate your Central Server IP

Ensure the central server is running on the same local network (Wi-Fi/LAN). Find its IPv4 address (e.g., 192.168.1.100).

Step 2: Enter the URL in Settings

Navigate to the Settings tab. In the "Local Server Sync" field, enter the full URL including the port (e.g., http://192.168.1.100:3000/sync).

⚙️
Local Server Sync

Step 3: Verification

Once saved, the app will silently attempt to push any unsynced completed or refunded orders in the background. If the central server is unreachable, the POS will keep the orders locally and try again later (Offline-First approach).

🛒 Basic Operations

  • Taking an Order: Click items from the menu, apply a discount if needed, and hit Checkout. Loyalty points are automatically awarded if a customer is selected.
  • Refunds: Go to the Orders tab, find the invoice, and click Refund. You can return specific items to auto-replenish the inventory stock.
  • Kitchen Printing: When an order is checked out, a customer receipt prints first, followed automatically by a larger, price-free Kitchen Ticket.
